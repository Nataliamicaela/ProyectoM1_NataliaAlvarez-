# 🎨 Generador de paletas de colores

Aplicación web que permite generar paletas de colores aleatorias en formato HEX o HSL, con posibilidad de copiar los valores fácilmente.

---

## 🚀 Funcionalidades

- Seleccionar cantidad de colores (6, 8 o 9)
- Generar colores aleatorios
- Elegir formato de color (HEX o HSL)
- Visualizar siempre el código HEX de cada color
- Copiar el color al hacer click
- Feedback visual mediante notificaciones (toast)
- Adaptación automática del color del texto para mejorar la legibilidad

---

## 🛠️ Tecnologías utilizadas 

- HTML5
- CSS3
- JavaScript (Vanilla)
- Git & GitHub

---

## 📦 Cómo usar la aplicación

1. Seleccionar la cantidad de colores
2. Elegir el formato (HEX o HSL)
3. Hacer click en **"Generar paleta"**
4. Hacer click sobre cualquier color para copiarlo
